# Ndlovu & Xaba Motors – Vehicle Administration System

## Project Overview

The **Ndlovu & Xaba Motors Vehicle Administration System** is a graphical user interface (GUI) application developed using **Python, PyQt5, and Qt Designer**.

The system was designed to assist a motor dealership with basic administrative activities such as user authentication, vehicle management, customer and booking management, and sales administration.

This project was developed as part of **INF2611 – Visual Programming II Assignment 4** at the **University of South Africa (UNISA)**.

## System Features

The application consists of four main GUI pages:

### 1. Login GUI

The Login GUI provides secure access to the system. The user enters a username and password, and the system validates the details before allowing access to the Vehicle Management page.

### 2. Vehicle Management GUI

The Vehicle Management GUI allows the user to capture and manage vehicle information. Vehicle details such as registration information, make, model, year, price and availability can be entered and managed.

### 3. Customer & Booking Management GUI

The Customer & Booking Management GUI allows customer information and vehicle booking details to be captured and managed. It provides an organised way of maintaining customer and booking records.

### 4. Sales & Summary GUI

The Sales & Summary GUI allows the user to capture sales-related information and provides a summary of dealership transactions.

## How to Run the Project

### 1. Install PyQt5

If PyQt5 is not already installed:

```bash
pip install PyQt5
```

### 2. Navigate to the Project Folder

Open Anaconda Prompt or Command Prompt and navigate to the folder containing the project.

Example:

```bash
cd "C:\Users\YourName\Desktop\Ndlovu Motors"
```

### 3. Run the Application

Run:

```bash
python nxmotors5.py
```

The Ndlovu & Xaba Motors application should open in a new window.

## Application Navigation

After successfully logging in, the user can navigate through the system:

**Login → Vehicle Management → Customer & Booking Management → Sales & Summary**

The Back and Next buttons allow navigation between the different pages of the system.
